# MySQL 작업 규정

- 데이터베이스에 임의로 직접 접속하여 쿼리 및 명령을 실행하지 않는다
- 데이터 접근은 기존 애플리케이션 코드와 테스트 구성을 통해 수행한다
- DB 스키마와 데이터 접근 코드를 변경할 때는 기존 애플리케이션 코드와
  설정을 통해 접근 방식을 확인한다
- 연결 문자열, 비밀번호, 인증 토큰 및 접속 정보가 포함된 파일을
  출력하거나 외부로 전송하지 않는다
- 데이터베이스 변경 및 마이그레이션 파일은 작성할 수 있지만,
  실제 DB에 적용하는 작업은 별도 승인을 받는다
- 기존 Repository, Redis 접근 계층 및 MongoDB 접근 계층을 재사용한다
- 각 저장소의 역할과 데이터 소유권을 임의로 변경하지 않는다
